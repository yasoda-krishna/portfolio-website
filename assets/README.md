# Assets Directory

This directory contains all static assets for the portfolio website.

## Structure

- **images/**: Contains all image files used in the portfolio
  - Project images
  - Profile images
  - Icons and logos

## Adding Images

When adding new images:
1. Use descriptive filenames
2. Optimize images for web (compress to reduce file size)
3. Use appropriate formats (JPEG for photos, PNG for graphics with transparency, SVG for icons)
4. Consider adding multiple sizes for responsive design
